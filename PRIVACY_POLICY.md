# Privacy Policy for Arrow Puzzle

**Effective date: July 15, 2026**

Arrow Puzzle is an offline Android puzzle game. This Privacy Policy explains how the application handles information.

## Information collection

Arrow Puzzle does not collect, request, store, transmit, sell, or share personal information.

The application does not require:

- User registration or an account
- A name, email address, phone number, or precise location
- Access to contacts, photos, files, camera, microphone, or device identifiers
- An internet connection

## Game data

The current level, board, and move count are used only while the application is running. The current version does not upload this information to any server and does not use it to identify the user.

## Analytics, advertising, and third-party services

The current version of Arrow Puzzle does not contain advertising SDKs, analytics services, crash-reporting services, Firebase services, or other third-party systems that collect user data.

## Children’s privacy

Because Arrow Puzzle does not collect personal information, it does not knowingly collect personal information from children.

## Data security

No personal data is collected or transmitted by the current version of the application. Users should still keep their Android device and operating system updated as a general security practice.

## Future changes

If a future version introduces online features, advertising, analytics, accounts, cloud saves, or any other form of data collection, this Privacy Policy must be updated before those features are released.

Changes will be published in this file with a revised effective date.
